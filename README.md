# Python Type Annotations — Learning Tasks

Практическое задание по изучению системы статической типизации Python.

## Описание

Проект содержит набор задач, демонстрирующих использование различных конструкций модуля `typing` и встроенных аннотаций типов Python 3.15. Каждая задача реализована в отдельном модуле и покрывает конкретную тему типизации.

## Темы

| Модуль | Тема |
|---|---|
| `any` | Тип `Any` — отключение проверки типов |
| `await_foo` | Аннотации для асинхронных функций и `Awaitable` |
| `callable` | Тип `Callable` — аннотация функций-обратных вызовов |
| `class_var` | `ClassVar` — переменные класса |
| `decorator` | Типизация декораторов с `TypeVar` |
| `dict` | Аннотация словарей `dict[K, V]` |
| `empty_tuple` | Пустой кортеж `tuple[()]` |
| `final` | `Final` — константы и финальные классы/методы |
| `generic`, `generic2`, `generic3` | Обобщённые типы и `TypeVar` |
| `instance_var` | Переменные экземпляра |
| `kwargs` | Аннотация `**kwargs` |
| `list` | Аннотация списков `list[T]` |
| `literal` | `Literal` — фиксированные значения |
| `literalstring` | `LiteralString` — строки как литералы |
| `optional` | `Optional` — допуск значения `None` |
| `parameter` | Аннотация параметров функций |
| `return_foo` | Аннотация возвращаемых значений |
| `self` | `Self` — тип возвращаемого экземпляра |
| `tuple` | Аннотация кортежей `tuple[T, ...]` |
| `typealias` | Псевдонимы типов |
| `typed_dict`, `typed_dict2`, `typed_dict3` | `TypedDict` — структурированные словари |
| `union` | `Union` — объединение типов |
| `unpack` | `Unpack` — распаковка `TypedDict` |
| `variable` | Аннотация переменных |

## Инструменты

- **mypy** — статическая проверка типов
- **flake8** — линтер стиля кода

## Запуск

```bash
# Установка зависимостей
uv sync --dev

# Проверка типов
uv run mypy main.py src/

# Линтинг
uv run flake8 main.py src/
```

## Сборка Docker-образа

```bash
make docker-run
```

## Запуск проверки типизации с помощью mypy

```bash
make typing
```
